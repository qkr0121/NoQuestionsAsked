지금까지 구현 완료된 핵심 클래스만 추려서 정리했습니다. UI 표시 전용 클래스(GameOverUI, LoadingScreen 등)와 세이브 DTO는 생략했습니다.

실선 화살표 = 참조/호출 (A가 B를 사용) 채워진 마름모 = 소유 (A가 B를 필드로 가짐) <<Singleton>> = static Instance 싱글톤

읽는 법

  • <<Singleton>> 표시가 붙은 클래스는 static Instance 싱글톤으로, PersistentManagers 프리팹에 상주하며 씬 전환에도 유지됩니다.
  • 점선 화살표(..>)는 "이 클래스가 저 클래스의 메서드/프로퍼티를 호출한다"는 뜻입니다. 예: PlayerHealth가 PlayerManager.Instance.SetCurrentHealth()를 호출.
  • 실선 마름모(*--)는 소유 관계입니다. 예: PlayerWeapon이 WeaponData(ScriptableObject)를 필드로 들고 참조.
  • <<ScriptableObject>> 표시가 붙은 클래스는 씬에 배치되는 컴포넌트가 아니라, 값만 담은 데이터 에셋입니다.
