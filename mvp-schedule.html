읽는 법 · 위험 평가

  • 진행 순서는 이슈 번호(1~18) 순이 아니라 작업 흐름 기준으로 재배열: 상점 → 좀비+방어벽(연관) → 무기 다중화·반동·수류탄(가장 무거운 작업, 중간에 몰아서) → 회복약+핫바(슬롯 연동 자연스러움) → 맵 확장+스폰인디케이터 → 지원동기+미션조정 → GameUI 재작성+전투피드백(데이터가 갖춰진 뒤에 레이아웃) → 엔딩+튜토리얼(맨 마지막).
  • 10/5~10/9: 무기 다중화 아키텍처 재설계 + 반동 + 수류탄 신설이 겹치는 구간이라 지연 가능성이 가장 높다.
  • 10/12~10/13: GameUI 재작성 · 전투 피드백 · 엔딩 · 튜토리얼 2개가 마지막 이틀에 몰려 있어, 실제로는 10/14~15로 자연 연장될 가능성이 가장 높은 지점.
  • 92시간 예산은 그대로 유지하고 새 작업을 최대한 욱여넣어 시도하되, 안 되면 10/14~15로 연장하는 것을 허용 — 칼같이 맞춰야 한다는 강박은 없음.
  • 3D 모델 제작(좀비 2종·무기 2종·수류탄 1종·방어벽)은 이 표와 별개로 주말(10/3~4, 10/10~11)에 병행 진행하는 별도 예산.
