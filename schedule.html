단계별 상세 안내

「No Questions Asked」(생존 웨이브 디펜스) 기준. 실제 스코프 결정에 맞춰 작성했습니다.

MVP

9/29 ~ 10/13 · 15일

목표28일 완주가 하나의 런으로 성립하는 생존 디펜스 핵심 루프(전투 → 상점 → 강화 → 재도전)를 완결된 상태로 만든다.

  • 구현 완료: 씬 4개 구조(메인메뉴·로딩·기지·전투장), 영속 매니저·세이브 아키텍처, 웨이브/좀비/무기 시스템 뼈대, 무기 강화·탄약·재장전, 방어벽 핵심 로직(설치·수리·상태 관리), 3D 모델(플레이어·좀비·구조물) 적용
  • 구현 예정(무조건 완료): 상점 UI 완성(무기 강화, 방어벽 설치·수리), 지원 동기 질문(9종 중 선택, 순수 연출), 좀비 2종, 무기 2종 + 수류탄 1종, 좀비의 방어벽 공격 로직, 전투 피드백 최소 세트(총구 화염, 피격 플래시, 재장전 게이지바), 런 28일 엔딩(최종 크리스탈량 + 선택한 동기에 대응하는 결과 텍스트 1개)
  • 구현 예정(순서대로, 시간 되는 데까지): 좀비 3종째 추가와 그에 맞춘 웨이브 10개 다양화(좀비 구성 비율·스폰 방향·스폰 간격 조합) → 무기 3종째 → 수류탄 2·3종째. 중간 어디서든 끊어도 됨
  • 제외(CBT·OBT로 미룸): 카메라 셰이크·피 파티클 등 타격 피드백 디테일, 신규 콘텐츠의 실제 3D 모델(MVP는 프리미티브로 대체), 방어벽 실제 모델(현재 프리미티브), 사운드, 엔딩 텍스트 확장(동기별 1개 → 크리스탈량 구간별 2·3개), HUD 등 UI 비주얼 다듬기
  • 클로드 활용: 새 아키텍처 결정은 함께 논의(작업 예고 → 개념 설명 → 질문 → 승인 → 구현), 반복되는 패턴(좀비 3종째, 웨이브 추가 등)은 빠르게 진행
예시 지금은 웨이브 1개·좀비 1종·무기 1개뿐이라 상점에 갈 이유도, 강해지는 감각도, 28일을 버틸 이유도 없다. MVP가 끝나면 미션(7일 주기 크리스탈 상납)을 갚아가며 28일을 완주하고, 마지막에 최종 크리스탈량과 선택한 동기에 따른 짧은 결말을 보게 된다.

완료 기준런 시작(동기 선택)부터 28일 엔딩까지 막힘 없이 완주할 수 있는가.

CBT

10/14 ~ 10/18 · 5일

목표지인 3~5명에게 플레이시켜 설명 없이도 이해되는지 확인하고, 여유가 생기면 계획된 확장을 진행한다.

  • 포함: 빌드 배포, 지인 3~5명 섭외, 피드백 수집, 치명적 문제(진행 불가, 이해도 문제) 우선 수정
  • 여유 시 확장: 무기·수류탄 3종째, 타격 피드백 디테일(카메라 셰이크, 피 파티클) 등 이미 재미가 확인된 요소만
  • 클로드 활용: 피드백 정리와 우선순위 분류, 버그 원인 분석, 밸런스 수치 조정
예시 지인 5명에게 빌드를 보냈더니 3명이 "상점에서 뭘 사야 할지 모르겠다"고 답했다. 강화 버튼에 효과 설명을 붙이고, 2명이 지적한 "좀비가 방어벽을 안 때리는 것 같다"는 부분을 확인해 판정 범위를 조정했다.

완료 기준테스터가 설명 없이도 루프를 이해하고 끝까지 플레이하는가.

OBT

10/19 ~ 10/24 · 6일

목표기능 추가를 멈추고 다듬는다. 공개 범위를 넓혀 예상 못 한 문제를 찾는다.

  • 포함: 사운드·이펙트 보강, UI 정리, 성능 최적화(오브젝트 풀링 등 확인), 여러 PC 환경 실행 확인
  • 공개 범위: 커뮤니티, SNS 등 모르는 사람도 접할 수 있는 곳에 링크 공유
  • 클로드 활용: 리팩터링, 성능 병목 분석, 스토어 소개 문구·플레이 가이드 초안
예시 공개 링크를 올렸더니 저사양 노트북에서 좀비가 늘어날 때 프레임이 떨어진다는 제보가 왔다. 오브젝트 풀 크기와 스폰 간격을 재점검해 안정된 프레임으로 고쳤다.

완료 기준새로운 치명적 버그 제보가 연속 2일 이상 들어오지 않는가.

출시

10/25 ~ 10/28 · 4일

목표더 이상 손대지 않을 최종본을 확정하고 발표를 준비한다.

  • 포함: 최종 빌드 생성, 배포 페이지 정리, 스크린샷, 발표 자료
  • 규칙: 10/26 이후에는 새 기능 금지, 버그 수정만 허용
  • 클로드 활용: 발표 스크립트 작성, 예상 질문 정리, 시연 시나리오 점검
예시 최종 빌드를 확정하고 배포 페이지를 공개했다. 시연 중 게임이 멈출 경우를 대비해 백업 영상도 녹화하며 두 번 리허설했다.
